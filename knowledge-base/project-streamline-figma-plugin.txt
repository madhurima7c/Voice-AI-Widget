STREAMLINE — Figma plugin for icons (2023)
Domain: B2B SaaS — design tooling / Figma ecosystem
Timeline: 3 weeks
Role: Product Designer
Team: Founder, developer
Site: /work/streamline-plugin

SUMMARY CARD
Designers wanted Streamline inside Figma. Competitor icon plugins were on-canvas; paying Streamline users had to leave Figma to browse and export. She designed search, browse, customize, and drag-to-canvas in three weeks.

THE PROBLEM
Streamline was losing reach and retention because it wasn't where designers work. Paying users faced friction leaving Figma; users requested a native plugin (Canny).

THE SOLUTION
- Drag-and-drop icons straight onto the canvas — no export/download hop.
- Packed web-app features into a narrow plugin shell with progressive disclosure.
- Expandable panel: compact for search-and-drop, grows for deeper customization.
- Learned Figma plugin guidelines and worked closely with engineering on constraints.

OUTCOMES (Figma Community, portfolio)
- Liked by 6.3K+ users; used by 452K+ users
- Won Figma “Favourite Graphic Resource” award
